# Textes Notre Approche - OPENDOOR

## Section "Notre façon de travailler"

### Titre
"Notre façon de travailler"

### Sous-titre
Un accompagnement clair, du premier appel jusqu'à la fin de l'intervention.

---

## Les 4 Piliers

### 1. Écoute

**Titre** : Écoute

**Description** : Nous comprenons que ce moment est stressant. On prend le temps de vous rassurer.

**Icône** : Oreille / Coeur

---

### 2. Clarté

**Titre** : Clarté

**Description** : Le tarif est annoncé avant l'intervention. Vous savez exactement à quoi vous attendre.

**Icône** : Document / Checklist

---

### 3. Soin

**Titre** : Soin

**Description** : Ouverture fine privilégiée. On respecte votre porte comme si c'était la nôtre.

**Icône** : Main / Outil de précision

---

### 4. Confiance

**Titre** : Confiance

**Description** : Serruriers qualifiés, matériel certifié. Vous êtes entre de bonnes mains.

**Icône** : Badge / Bouclier
